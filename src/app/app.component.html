AEM Fragment Embed

Embeddable AEM content fragments — custom element + Shadow DOM, drop into any HTML page

⚠️ These embeds use a lightweight loader instead of the stock aem-embed.js: the source project's own scripts.js bootstraps AEM Commerce config and assumes it owns the page, which throws when run inside a foreign host. Also note the source project (main--vwr--ynaka-adobe.aem.page) does not currently send an access-control-allow-origin header, so the fetches below may fail with a CORS error in the browser console unless you've enabled it (e.g. via a CORS-unblocking extension, or on the source project itself). See the README for details and the real fix.

This panel loads <fragment-embed>, a custom element defined in /scripts/fragment-embed.js, built following the aem-embed pattern (custom element + Shadow DOM, driven by a single url attribute). It fetches the fragment's .plain.html inside a Shadow DOM and loads the matching block's CSS/JS (/blocks/hero-lab/hero-lab.js and .css).

The same <fragment-embed> element, pointed at a different fragment/block pair to show it's not hero-lab-specific: fragments/card-fragment (served from the .aem.live domain) using the blocks/cards-category block.
